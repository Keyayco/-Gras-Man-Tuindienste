GRAS MAN TUINDIENSTE
Standalone vanilla website

OPEN LOCALLY
Double-click index.html. No Node.js, npm, build command or server is required.

EDIT THE BUSINESS
Main page content is in index.html. Phone, WhatsApp and address details appear in the contact, hero and footer sections.

REPLACE IMAGES
Replace assets/images/garden-hero.png with another image using the same filename, or update the image paths in index.html and css/style.css.

EDIT COLOURS
Update the CSS variables at the top of css/style.css. The main brand colours are --green, --green-2, --sand and --paper.

EDIT WHATSAPP / PHONE
Update the tel: links and the wa.me/27655252052 links in index.html and js/script.js. Keep the WhatsApp number in international format without spaces: 27655252052.

DEPLOY
Upload this folder to GitHub Pages, Netlify Drop, or any static web host. The entry point is index.html.
